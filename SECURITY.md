# Security reports

Report a vulnerability privately using [GitHub's Report a vulnerability
form](https://github.com/nbobby07/astraeus/security/advisories/new).
Do not put exploit details, credentials or private signing material in a public
issue. Ordinary bugs belong in the issue tracker.

Include the affected revision, environment, reproduction steps, impact and any
workaround you have verified. Redact personal data. There is no guaranteed
response time or paid security support.

## Supported state

This is a development repository. Reports against current `main` and the recorded
Phase 1 implementation are useful; there are no maintained stable release lines.
The archived snapshot is a reproducible build input, not a security-update service.
Do not treat the development image as a maintained production workstation.

Upstream vulnerabilities should also be reported through the affected project's
process. Astraeus-specific integration defects belong here.

See [security and signing](docs/security.md) for repository verification,
installer privileges, development signing identities and the Secure Boot boundary.
